# M01 — Canonical PaperDocument & Parse Quality Gate

> M01 is stacked on top of M00. Review or merge M00 first; do not merge this
> branch directly into main until its parent changes land.

## Delivered

1. `domain/paper_document.py`: schema v1, immutable DocumentNodes, source
   section anchors, original arXiv/revision split, deterministic content hash
   and stable content-derived paragraph IDs. IDs survive reimport and insertion
   of a different paragraph in the same section. Duplicate same-text siblings
   use occurrence counters and remain unambiguous, but can shift if another
   identical sibling is inserted earlier.
2. `ParseQuality`: status `full|partial|metadata_only|unavailable`, diagnostic
   warnings and structural counts. Full-text cache requires body paragraphs.
   Old title-only cached payloads are invalidated and refetched. Papers with
   neither metadata nor usable HTML are rejected before Notion calls.
3. `papers/{category}/{arxiv_id}/document.json`: canonical artifact saved
   independently of Notion and model results.
4. HTML nested subsection parsing is bounded by nearest parent section,
   preserving source anchors and MathML; display math falls back to TeX
   annotations; figure URLs are resolved relative to source URL.
5. Notion rendering no longer silently truncates rows, subsections, long
   text, reference lists or equation arrays. Unsupported oversized inputs
   now fail explicitly instead of masquerading as complete imports.
6. Annotation cache uses SHA-256 of canonical content, model, prompt,
   generation settings and cache schema. A version manifest binds these
   inputs to exact on-disk JSONL bytes and entry count. Legacy files without
   a manifest are invalidated. Failed annotations cannot be cached as success.
7. Notion paragraph notes join on canonical node IDs to avoid duplicate
   section-name collisions; legacy annotations are still readable.

## Quality semantics

`full` means structurally nonempty text and abstract were identified. It is
NOT an assertion that the entire publisher's paper matches the ar5iv HTML.
`partial` reports missing sections, body paragraphs, abstract or title.
`metadata_only` means no trustworthy full text is available but metadata
may be sufficient for a fallback Notion page. `unavailable` prevents import
if no metadata and no useful full text are present.

The source locator is an HTML section anchor, **not a fabricated byte offset**.
No PDF-based structural fallback or manually verified section-level gold corpus
is part of this release.

## Lossless Notion text boundary

Rich-text objects larger than 2000 characters are segmented into multiple
elements, preserving whitespace exactly. A single array over 100 elements
fails preflight rather than being truncated. A renderable LaTeX expression is
required for a Notion equation block; unrenderable MathML-only equations remain
in the canonical artifact and fail Notion rendering explicitly.

## Markdown preservation

`content.md` now exports paragraphs, equations, figures, tables and references
in document order. Missing LaTeX with available MathML uses an XML fenced
block, while structured JSON remains the canonical source of truth.
