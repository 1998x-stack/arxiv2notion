# M02.1 — Read-only live certification gate

The read-only CLI is complete, but **live Notion writes have not been tested**.
Use a disposable Notion root with authorized credentials.

```sh
export NOTION_TOKEN=...
export NOTION_ROOT_PAGE_ID=...
python verify_notion.py --remote
python verify_notion.py --db ./data/imports.sqlite3
```

The CLI checks page visibility, paginated child reading and SQLite job states;
it never changes Notion or the database. It must not be described as a live
write E2E certification.

Operator-run sandbox write test: (1) import a paper (2) reimport unchanged
(3) verify one page (4) inject lost create/append responses using a controlled
proxy (5) reconcile remote state (6) confirm manual edits cause conflict.
Record results privately, without credentials or private page data in Git.
