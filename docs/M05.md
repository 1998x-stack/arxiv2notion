# M05 — Local Research Workspace

A local read-only browser for the paper catalog built in M03, the citation
graph and the evidence review artifacts from M04.

## Start

```sh
python -m research.cli index --papers-root ./papers
python -m research.web --host 127.0.0.1 --port 8765
```

Open http://127.0.0.1:8765 in your browser. No Notion token or LLM key is
needed for browsing. This workspace uses only Python's standard-library HTTP
server, native JavaScript, CSS and the SQLite catalog.

## Features

- Search by arXiv ID, title or abstract.
- View full canonical document nodes and parsing quality.
- Inspect outgoing references and incoming citations.
- Browse source-bound annotation claims, numerical warnings and latest human
  review verdict, with links to the original arXiv/ar5iv source.
- Responsive keyboard-accessible layout and explicit loading/error states.
- HTML is fixed local assets; user content uses textContent, not innerHTML.

## Safety boundaries

- The HTTP server binds to loopback by default. Non-loopback requires an
  explicit `--allow-network` flag, and has **NO AUTHENTICATION**. Use a VPN,
  reverse proxy with auth, or localhost tunneling for any remote access.
- Only GET endpoints; POST, PUT and DELETE are disabled.
- No remote Notion write, no login/session management, no cloud telemetry.
- Data in the index and claims is local and potentially private. Never expose
  this service directly to the public Internet.
- Responses carry a strict Content Security Policy, anti-sniffing and
  no-store headers. All filesystem reads are tied to fixed routes or
  validated arXiv IDs; there is no generic file-serving endpoint.
- Human review actions are intentionally recorded through
  `python -m research.review_cli` rather than browser writes.

## Routes

`/api/overview`, `/api/search?q=...`, `/api/paper?id=...`,
`/api/citations?id=...`, `/api/backlinks?id=...`,
`/api/claims?id=...`.

## Explicit limits

This is a local-first **minimum viable workspace**, not a deployed production
multi-user web app. Authentication, collaborative review editing, pagination
for >100 search results, and remote deployment are outside M05.
