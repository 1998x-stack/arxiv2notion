# M03 — Paper catalog & citation provenance

M03 is stacked on PR #4 (M02.1). It introduces a local, offline research
index and citation graph (SQLite), separate from Notion imports.

- Paper identity: exact arXiv ID (including revisions); citation targets use
  version-insensitive base IDs for inbound references.
- Each extracted citation is an independent evidence edge preserving original
  order, raw text and citation key. Duplicates are not thrown away.
- Targets are identified by explicitly valid arXiv IDs or DOI strings.
  Text-only matches are retained as *unresolved*; no fuzzy-title identity merges.
- Catalog upsert replaces a document's edges transactionally and is safe to
  rerun. Indexes include the canonical content hash and full document JSON.
- Ingestion happens after reference resolution but before remote Notion writes,
  so an API outage does not prevent offline research indexing.
- The index may be rebuilt from `papers/*/*/document.json`.

Usage (does NOT require Notion credentials):

```sh
python -m research.cli index --papers-root ./papers
python -m research.cli overview
python -m research.cli search "attention"
python -m research.cli paper 1706.03762
python -m research.cli citations 1706.03762
python -m research.cli backlinks 2401.12345
```

Optional: `CATALOG_DB=./data/catalog.sqlite3`. Keep the database out of Git.
`citation` is a source reference, not a scientifically verified endorsement.
The CLI and catalog are local; no hosted search server or external graph DB
is introduced in M03.
